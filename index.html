Automatic Drug Dispenser

A cabinet-style machine that hands out medicine only after it verifies a doctor-issued prescription by QR code.

  • Hardware: four-shelf cabinet with DC motors, driven by a Raspberry Pi 4 running Python, with a QR scanner.
  • MediDispense web app: custom React and Vite app with doctor login, patient login, QR generation and a machine finder map.
  • End to end: doctor issues, patient scans, machine releases the medicine.

Raspberry Pi 4, Python, DC motors, QR scanner, React, Vite

Smart Gesture Glove

A glove that turns hand gestures into text, to help speech-impaired people communicate.

  • Five flex sensors, one per finger, read by an Arduino Uno in real time.
  • Gesture to text on a 16x2 LCD, with a phrase mapped to each finger.
  • Simulated first in Tinkercad before assembly.

Arduino Uno, flex sensors, Embedded C, 16x2 LCD, Tinkercad
